Política de Privacidade

Última atualização: 18 de março de 2026

O Iacula é um aplicativo de oração que respeita sua privacidade. Esta política descreve quais dados são coletados, como são utilizados e como são protegidos.

1. Dados coletados

Conta e autenticação (opcional):

  • Se você optar por criar uma conta (via Google, Apple ou Microsoft), coletamos seu nome e endereço de e-mail fornecidos pelo provedor de autenticação.
  • O app funciona sem conta; nesse caso, nenhum dado pessoal é coletado.

Dados espirituais:

  • Anotações de exame de consciência, intenções de oração e diário espiritual são armazenados localmente no seu dispositivo de forma criptografada.
  • Se você estiver autenticado, esses dados podem ser sincronizados com nosso servidor (Supabase) para backup e acesso entre dispositivos.

Dados locais (não sincronizados):

  • Favoritos, frases personalizadas, marcadores de leitura, registro de atividade de oração e configurações ficam armazenados apenas no seu dispositivo.

Compras no app:

  • Se você adquirir o acesso premium, armazenamos o status da compra e o identificador da transação da loja (Google Play ou App Store) para validação.

2. Dados que NÃO coletamos

  • Localização ou dados de GPS
  • Contatos, fotos ou arquivos do dispositivo
  • Identificadores de publicidade
  • Dados de analytics ou rastreamento de terceiros
  • Relatórios de crash enviados a terceiros

3. Como usamos os dados

  • Autenticação: para identificar sua conta e permitir a sincronização.
  • Sincronização: para manter seus dados espirituais acessíveis entre dispositivos.
  • Compras: para validar e restaurar o acesso premium.

4. Compartilhamento de dados

Não vendemos, alugamos ou compartilhamos seus dados pessoais com terceiros. Os dados sincronizados são armazenados em servidores Supabase com acesso restrito ao seu usuário.

5. Segurança

  • Dados espirituais são armazenados localmente com criptografia.
  • A comunicação com o servidor utiliza HTTPS/TLS.
  • Chaves de criptografia são armazenadas no armazenamento seguro do dispositivo (Keychain/Keystore).

6. Exclusão de dados

Você pode excluir seus dados a qualquer momento:

  • Dados locais: desinstale o app.
  • Dados sincronizados: entre em contato conosco pelo e-mail abaixo para solicitar a exclusão completa da sua conta e dados do servidor.

7. Serviços de terceiros

  • Supabase: autenticação e sincronização de dados (política de privacidade).
  • Google Play / Apple App Store: processamento de compras no app.
  • API litúrgica: consulta de dados do calendário litúrgico (nenhum dado pessoal é enviado).

8. Crianças

O Iacula não é direcionado a menores de 18 anos. Não coletamos intencionalmente dados de crianças.

9. Alterações nesta política

Podemos atualizar esta política periodicamente. A data de atualização será indicada no topo desta página.
