# Iacula

Um aplicativo minimalista focado no envio programado de jaculatórias e momentos de oração breve.

## Objetivo do Projeto
O Iacula foi desenvolvido para atuar como um lembrete de presença no cotidiano. Através de notificações em horários definidos, o aplicativo apresenta uma jaculatória (oração curta) acompanhada de uma imagem contemplativa, sem funcionalidades de rede social, feeds ou elementos de distração.

## Funcionamento Técnico
O projeto utiliza uma estrutura focada em performance e baixo consumo de dados:
- **Interface:** Construída em Flutter, priorizando uma UI limpa e direta.
- **Notificações:** Sistema de agendamento de avisos para entrega do conteúdo.
- **Widgets:** Integração nativa com iOS para exibição de jaculatórias na tela de início.
- **Backend:** Supabase para autenticação de usuário e armazenamento de frases e imagens.

## Política de Privacidade
O Iacula respeita a privacidade do usuário e cumpre as diretrizes da App Store:
- **Dados Coletados:** Coleta de e-mail (para fins de autenticação via Supabase) e identificadores técnicos necessários para o funcionamento das notificações push.
- **Uso de Dados:** Os dados são utilizados exclusivamente para o funcionamento técnico do aplicativo. Não há compartilhamento de dados com terceiros nem rastreamento para fins publicitários.
- **Exclusão de Dados:** O usuário pode solicitar a exclusão de sua conta e dados associados a qualquer momento através das configurações do app ou entrando em contato via suporte.

## Suporte e Contato
Para suporte técnico, dúvidas sobre o funcionamento do aplicativo ou solicitações de privacidade, entre em contato através das *Issues* deste repositório ou pelo e-mail de suporte cadastrado na App Store.
