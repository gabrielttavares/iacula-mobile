# Iacula

Um aplicativo minimalista para o envio programado de jaculatórias e momentos de presença.

## Objetivo do Projeto
O Iacula atua como um ponto de interrupção no fluxo automático do cotidiano. Através de notificações em horários definidos, o aplicativo apresenta uma jaculatória (oração curta) acompanhada de uma imagem contemplativa, sem funcionalidades de distração.

## Funcionamento Técnico
O projeto utiliza uma estrutura focada em performance e baixo consumo de dados:
- **Interface:** Desenvolvida em Flutter com foco em minimalismo.
- **Notificações:** Sistema de agendamento local para entrega do conteúdo.
- **Widgets:** Integração nativa com iOS para exibição de jaculatórias na tela de início.

## Política de Privacidade
O Iacula respeita as diretrizes de privacidade da App Store:
- **Dados Coletados:** Identificadores técnicos para notificações.
- **Uso:** Exclusivamente para o funcionamento do app. Não há compartilhamento com terceiros nem rastreamento publicitário.
